# NES.emu 改修履歴

## 1.5.85-touch3（2026-10-03）

- 相対方向入力で不要になった固定十字キーの仮想ボタングループを既定レイアウトから外した。左半分のジェスチャー入力は維持。
- Select を右側へ移し、Start と横並びにした。
- 現在の実機表示に合わせて画面比率の既定値を 1:1 にし、右側の余白に収まるよう A/B ボタンを大きくした。ボタンは不透明を既定とし、押下時のハイライトを維持。
- 前版の入力診断ログは、操作時の負荷を避けるため通常版から除いた。

## 1.5.85-jinn.2（2026-10-03）

- 相対十字キーの取りこぼし調査用に、タッチイベント、入力採用条件、6dp判定、キー送出、NES のボタン状態を Android ログへ記録する診断版。

## 1.5.85-jinn.1（2026-10-03）

- 元版 1.5.85 を基にした初回改修。
- Android のタッチ方向入力を、左画面内の接地点を起点とする相対操作へ変更。6dp の移動で方向を切り替え、指を離すまで保持する。斜め入力に対応。
- 固定十字キーのタッチ判定を NES.emu では無効化。A/B ボタンと物理コントローラーの入力経路は維持。
- Android のアプリ名とパッケージIDを `NES.emu Touch` / `local.jinn.nesemutouch` とし、元の NES.emu と並べて試せるようにした。
- ARM64 APK をビルドして Xiaomi Pad 6 にインストールし、ゲーム内で右方向への移動を確認。入力の遅延や取りこぼしは未検証。
